# Lang

My Chinese and Japanese conversation tutor. It runs as chat sessions with Claude: I type `/tutor`, pick 中文 or
日本語, and we talk. Each turn, Claude answers with a table that marks what was natural in my sentences, corrects
what wasn't, replies, and gives me a frame for my answer.

This repo is the tutor's memory between sessions:

- `Tutor.md`: how the tutor works, and my level and common mistakes in each language.
- `Memory.md`: what the tutor knows about me, so it doesn't ask the same things twice.
- `Vocab.md`: words from the sessions and how well I know them.
- `conversations/`: notes from every session, and my old Chinese diaries.
