# Chinese tutor session: 2026-10-21

Level: beginner, Immersive Chinese lesson 80. Topic: conversation (Japan, money, internship, work, lunch, music, studying Chinese on the bus, the Lang app, AI projects).

## Patterns to watch

| | |
|---|---|
| Wrong character from the pinyin keyboard (more than half of the unclear sentences) | 快→**钱**/块, 挺→**听**, 帮衬/比昂辰→**编程** |
| Verb + quantity + object: quantity goes after the verb | 东西买很多 → 买**很多东西** |
| Time word, then place, then verb | 用公交车上班的点学习中文 → 上班的时候,**在公交车上**学习中文 |
| No 的 after a bare time word | 每天十一点**的** → 每天十一点 |
| Two clauses are not joined with 和 | 我想学中文**和**AI的编程很好 → split into two sentences |
| Lists: 、 and 和 only before the last item | app、模组**和**文件 |
| English words as gaps (still the main way a sentence breaks) | still, restaurant, OK, internship, memory, mods, documents, 3D models |

## Gap words (English the learner used)

still → 还; restaurant → 饭店 (lesson 67, already known); OK → 还可以 (lesson 47); internship → 实习 shíxí;
word → 词 cí; something else → 别的 biéde; memory → 记忆 jìyì; help → 帮助 bāngzhù; mods → 模组 mózǔ;
documents → 文件 wénjiàn; 3D models → 3D模型 móxíng; dating → 约会 yuēhuì (the learner's own word). Taught by me: 食堂 shítáng (canteen).
