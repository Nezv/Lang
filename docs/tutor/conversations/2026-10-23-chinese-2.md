# Chinese tutor session: 2026-10-23 (second session)

Level: beginner, A1, Immersive Chinese lesson 80. Topic: the Minecraft mod and its 3D models (dinosaurs, items, tech tree), using Claude on the phone any time and from a distance, and a 之类的/等等/就像那样 lesson on request. The other session of the day (family, commute) is in `2026-10-23-chinese.md`.

## Patterns to watch

| | |
|---|---|
| English words as gaps (7, most of them forced by my specific questions about the mod) | mod, dinosaurs, items, progression tree, velociraptor, classic, anytime |
| A measure word after a number | 四十dinosaurs模型 → 四十**个**恐龙模型 |
| 和 between every list item (again) | …模型和…模型和…… → A、B**和**C |
| Wrong word from the pinyin keyboard | 可以→**可谓** (typing slip); 多 probably for 都 (my guess, the sentence stayed unclear) |
| 他 is for people; animals and things are 它 | 他很classic → **它**很经典 |
| 手机 for a mobile phone, not 电话 (telephone); no second 的 | 我的电话的用Claude → 我在**手机上**用Claude |
| 不 + 真的 needs 是 | 我不真的编程 → 我**不是**真的编程 |
| 玩 vs 做: the models are for making the mod | 玩Minecraft,我的mod → **做**自己的Minecraft模组 |
| 就像那样 means "just like that" (points at one thing); "and so on" is 之类的 or 等等 | 公交车,做饭以后,就像那样 → …做饭以后**之类的** |
| Works now | 我最喜欢…,因为…; 我的电脑在家,但是…; 我问Claude |

## Taught on request (the learner asked for a 之类的 / 等等 / 就像那样 lesson)

| | |
|---|---|
| 之类的 | After a list, "things like that"; spoken. 我喜欢汉堡、咖啡之类的。<br>Wǒ xǐhuan hànbǎo, kāfēi zhīlèi de. |
| 等等 | After a list, "etc."; more written. 我用AI做app、模组、文件等等。<br>Wǒ yòng AI zuò app, mózǔ, wénjiàn děngděng. |
| 就像那样 | "Just like that"; points at one thing, not "and so on". 我想做一个模组,就像那样。<br>Wǒ xiǎng zuò yí gè mózǔ, jiù xiàng nàyàng. |

## Tutor notes

- The learner doesn't want vocabulary that only my question forced (which dinosaur? which item?). Rule added to `Tutor.md` and `harness-spec.md`: ask questions the known words can answer.
- My slips: 明白 (not a known word) in a 💬 row; a wrong guess (下班以后) when 我多以后 was unclear.
