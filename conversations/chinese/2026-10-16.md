# Chinese tutor session: 2026-10-16

Level: beginner, Immersive Chinese lesson 80. Topic: conversation (coffee and tea, connectives, weekends, games, burgers, Japan).

## Format rules for next time

- Every sentence is shown as three lines: hanzi, pinyin, English.
- One table per turn. The first column is an emoji:
  - ✴️ natural part of my sentence
  - ⛔ unnatural part
  - ✔️ AI correction
  - 💬 teacher question or answer
  - 💡 idea for my answer (always the last row)
- No "why" explanation sections. Ask only one question per turn.
- No new vocabulary. Stay at lesson 80 level.

## Patterns to watch

| | |
|---|---|
| Wrong character picked by the pinyin keyboard | 查→**茶** chá, 并→**冰** bīng, 旺季→**忘记** wàngjì, 白→**百** bǎi, 日月→**日语** Rìyǔ |
| Adjectives usually take 很 | 中文难 → 中文**很**难 |
| Quantity comes after the verb | 很多喝咖啡 → 喝**很多**咖啡 |
| In lists, use 、 and put 和 only before the last item | 面包、牛肉、芝士**和**培根 |
| 还是 (or) is for questions; 和 (and) is for statements | 加咖啡**和**糖 |
| 两 before 百/千/万 | 二百克 → **两**百克 |
| 想 doesn't take 了 for "wanted"; use a time word | 我想了去日本 → **以前**我想去日本 |
| 和……一起 | 我一起女朋友 → 我**和**女朋友**一起** |
| 自己 + verb, no 的 | 自己的做汉堡 → 自己做汉堡 |

## Connectives practised

| Connective | Example |
|---|---|
| 和 / 但是 | 我喜欢茶,但是我不喜欢咖啡。<br>Wǒ xǐhuan chá, dànshì wǒ bù xǐhuan kāfēi.<br>I like tea, but I don't like coffee. |
| 因为……所以…… | 因为我的办公室卖茶,所以我开始喝茶。<br>Yīnwèi wǒ de bàngōngshì mài chá, suǒyǐ wǒ kāishǐ hē chá.<br>Because my office sells tea, I started drinking tea. |
| 如果……就…… | 如果没有苹果茶,我就喝一杯水。<br>Rúguǒ méiyǒu píngguǒ chá, wǒ jiù hē yì bēi shuǐ.<br>If there's no apple tea, I'll drink a cup of water. |
| 还是 (questions) | 你喜欢热的还是冰的?<br>Nǐ xǐhuan rè de háishi bīng de?<br>Do you like it hot or iced? |
| 虽然……但是…… | 虽然夏天很热,但是我觉得热咖啡很好喝。<br>Suīrán xiàtiān hěn rè, dànshì wǒ juéde rè kāfēi hěn hǎohē.<br>Although summer is hot, I think hot coffee tastes very good. |
| 一边……一边…… | 我一边工作,一边喝很多咖啡。<br>Wǒ yìbiān gōngzuò, yìbiān hē hěn duō kāfēi.<br>I drink a lot of coffee while working. |
