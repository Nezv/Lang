## Format rules for next time

- Same format as before: Japanese, romaji, English stacked in one cell; one table per turn; one question per turn.
- Write the learner's English words as gaps in ✔️, but a word they plainly know and only typed in English from habit (大学) is not a gap and stays out of `Vocab.md`.
- ですよね is natural in conversation: don't flag it. A sentence-final よね that shares an opinion is fine.
- Don't assume why the learner likes Japan. I said "the reason is anime" and the learner found that offensive: it is history, architecture and universities. Ask, don't guess.
- When meaning is unclear, give a best guess and a yes/no check, but make the check about the guess, not a new idea (my check about studying Japanese before going was backwards and came out "strange").

## Patterns to watch

| | |
|---|---|
| Wrong kana/kanji from the keyboard (same reading) | ビアトリクス→ビアつりキス, に→二, 深圳→新鮮 |
| で marks where you do it | 日本の大学勉強した → 日本の大学**で**勉強した |
| 住む = to live somewhere; 生きる = to be alive | 日本で生きたい → 日本に**住みたい** |
| から = "since" | 昔で → 昔**から** |
| ので and から both give a reason, use one | 勉強したので…生きたいから → …**から**、勉強しました |
| 見えます = looks like | と見ています → **に見えます** / みたい |
| 好きだった / 好きでした, not 好きなた | 好きなた → 好き**です** |
| 卒業 = graduate; 終わる = something ends | 大学終わった → 大学**を卒業します** |
| 大きな場所 is odd for a city | → 大きな**都市** |
