## Format rules for next time

- Same format as the Chinese sessions, with romaji in place of pinyin: Japanese, romaji, English stacked in one cell.
- One table per turn, emoji first column (✴️ ⛔ ✳️ ✅ 💬 💡; ✳️ replaced 🔷 on 2026-10-25), one question per turn, no "why" sections.
- **Don't ask about something the learner has just said.** (Asked "Tokyo?" right after they said Tokyo.) A yes/no
  check is only for meaning that is really unclear; read the learner's sentence again first.
- No Japanese word list exists, so new words come from corrections; keep tutor rows to common N5 words.

## Patterns to watch

| | |
|---|---|
| Wrong kanji from the IME (same reading) | 日本に→人本二, を→尾, 作ります→浸かります, 飲みます→見ます |
| ために after a verb: dictionary form, no の | 観ているのために → 見る**ために** |
| ある for things, いる for people; "go" is 行く | 日本にある → 日本に**行く** |
| Plain past + です doesn't combine | 書けたです → 書き**ました** |
| ます + のか doesn't combine | 作りますのか → 作り**ますか** / 作る**の**? |
| い-adjective negative is くない | 遅くじゃない → 遅**くない** |
| Moving through a place takes を | 市で歩く → 町**を**歩く |
| Counts take no particle before the verb | 二本に飲みます → 二本飲みます |
| One を per clause; "with" is と一緒に | 私と彼女をゲームをして → 彼女**と一緒に**ゲームをします |
| 自分で = by my own effort; 一人で = alone | 自分で食べて → **一人で**食べます |
| 午後12時 is noon | 午後１２時 → **夜の12時** / 午前0時 |
